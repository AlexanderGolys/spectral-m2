# Key reference

## Shell

| Key | Action |
| --- | --- |
| `Enter` | Submit complete input, or continue an incomplete construct. |
| `Shift+Enter`, `Alt+Enter` | Insert a newline. |
| `Up`, `Down` | Move vertically or recall history at the input boundary. |
| `PageUp`, `PageDown` | Scroll the feed. |
| `Shift+Left`, `Shift+Right` | Extend the input selection. |
| `Shift+Home`, `Shift+End` | Extend selection to a line boundary. |
| `Ctrl+Y` | Copy selected input or screen text. |
| `Ctrl+L` | Clear the input. |
| `Ctrl+/` | Open commands. |
| `Ctrl+O` | Open settings. |
| `Ctrl+D` | Toggle highlight debug. |
| `Ctrl+C` | Quit from the shell. |

## Split and previews

| Key | Action |
| --- | --- |
| `Ctrl+Enter` | Open a splittable command in a second pane. |
| `Ctrl+Left`, `Ctrl+Right` | Focus a pane, including in a collapsed narrow split. |
| `Ctrl+Shift+Left`, `Ctrl+Shift+Right` | Resize a visible split. |
| `Up`, `Down`, `PageUp`, `PageDown` | Scroll a preview. |
| `Left`, `Right` | Cycle output projections in output preview. |
| `Ctrl+Q`, `Ctrl+C` | Leave a preview instead of quitting Spectral. |

## Pickers

| Key | Action |
| --- | --- |
| `Up`, `Down` | Change the selected row. |
| `Left`, `Right` | Adjust a settings or style row. |
| `Enter` | Open or run the selected row. |
| `Ctrl+Enter` | Use the split variant of a splittable command. |
| `Esc` | Close the current picker or debug overlay. |
